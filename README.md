# SCM Performance Dashboard (Power BI)

## Overview
Developed an interactive Supply Chain dashboard to monitor operational efficiency and identify bottlenecks across inventory and supplier performance.

## Key Metrics
- Inventory Turnover Ratio
- Order Fulfillment Rate
- Supplier Lead Time
- Stock Availability %

## Business Impact
- Identified slow-moving inventory reducing holding costs
- Highlighted supplier delays affecting delivery timelines
- Improved visibility into stock shortages and demand gaps

## Tools Used
- Power BI
- Excel
- DAX
